# RUConnect

A 3D map of every event on Rutgers College Ave. An agent swarm turns flyers, Instagram posts, and event-board pages into events; buildings glow when something is happening; a voice assistant picks events and flies the camera to them.

Built at HackRU, Oct 10 to 11, 2026.

## Status

The repo holds the design only. The code scaffold is not here yet.

- Design spec: [`docs/superpowers/specs/2026-10-10-campus-events-design.md`](docs/superpowers/specs/2026-10-10-campus-events-design.md)
- Original brief: [`brainstorm.md`](brainstorm.md)

## Before the scaffold lands

- Read sections 8 and 9 of the spec: slice ownership, the rules that keep our agents from clashing, and onboarding.
- Do not push to `main`. Work on `<yourname>/<topic>` branches and open a pull request.
